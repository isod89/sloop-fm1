# 默认输入音长

**ENTRY LEN** 可以让你设一次音长，再连续输入。它用于 **SEQ → NOTES 的逐步输入**，不改变实时 REC、鼓格子、调式映射或整条轨的速度。

## 使用方法

1. 先保存要保留的工作循环。停止播放并退出 REC / REC READY，选合成轨 1–3。
2. 短按 SEQ，用 SELECT 找 PATTERN，设 **DIV=1/16**。这样一格是十六分音符。
3. 按住 HOME 打开菜单，SELECT 找 **SEQ** 分类。
4. **KNOB 3 → ENTRY LEN → 1/8**；**KNOB 1 → STEP ADVANCE → ON**。
5. 按 OCT− 退出，短按 SEQ，用 SELECT 找 **NOTES**，用 KNOB 1 选空白的第1步。
6. 依次按下并完全松开几个音。每个新音写成八分音符，即两格；光标会走 **1 → 3 → 5 → 7…**。

画面上方的 **NEW 1/8** 是“接下来新写的音长”；屏幕下方 KNOB 3 的 **LEN** 仍然是“当前选中音符的长度”。改旧音符不会改变新音长度偏好。

## 可选值

- **STEP**：原来的输入行为，放键后前进一格。
- **1/8**：八分音符。DIV=1/16 时两格，DIV=1/8 时一格。
- **1/4**：四分音符。DIV=1/16 时四格。
- **1/2**：二分音符。DIV=1/16 时八格。

这是设备级输入偏好，会记住；切轨时继续使用同一偏好，并按新轨的 DIV 换算。它不把已有音符统一改长，不改变 BPM，也不会开启一指和弦或改变琴键音高。

## 边界行为

- **STEP ADVANCE OFF**：音符仍按默认长度写入，但光标留在原位，方便重试。下一次按键会重写该步。
- **和弦**：POLY 下把几个键一起按住，写成同长度的一组音；全部松开后才前进。
- **MIDI 键盘**：在 NOTES 页，发送到当前所选轨的音也使用该长度。
- **后面已有起音**：默认长音在它前面截短并提示 `ENTRY: NOTE AHEAD`。光标前进实际写入的长度；随后在已有起音处按键仍会按原编辑方式替换它。
- **输入区或边界接上已有延音**：提示 `ENTRY: TIE AHEAD` 并保留原内容，避免新音意外继承别人的延音；请选择空白位置、原音起点，或先用旋钮整理已有音。
- **到循环末尾**：截短并提示 `ENTRY: PATTERN END`，放键后光标回到开头，不把尾音绕到第1步。
- **改已有音高**：在起音位置重新按键，会先收回被替换音的旧延音，再写所选默认长度。也可以继续用 PITCH/LEN 旋钮编辑。
- **在已有延音中间输入**：提示 `SELECT NOTE START`，先选原音的起点或空位。
- **复杂的已有重叠音**：某步还带着前面延续的音，会提示 `ENTRY: HELD NOTE HERE`；同起点和弦里各音长度不同时，提示 `USE NOTE EDIT KNOBS`。请用原有 PITCH/LEN 旋钮整理，或换空位输入，避免默认音长改坏原来的独立延音。
- **网格不能表示音长**：提示 `LEN NEEDS FINER DIV`，不写入。例如 DIV=1/4 无法放一个八分音符；改成1/16即可。部分三连音网格也需要更细的划分。
- **撤销**：一次输入和它生成的延音属于同一个撤销动作；EDIT + OCT− 撤销，EDIT + OCT+ 重做。沿用现有的一层历史。

不喜欢这个输入方式时，把 ENTRY LEN 设回 STEP。不支持此功能的旧固件会忽略这项偏好；项目格式与 MIDI 路由不变。
